# Creación Visual — Visual Media

> Contar historias con lenguaje visual y crear imágenes memorables.

## Cuándo aplica

- Composición y técnica fotográfica
- Planeación y producción de video
- Creación de contenido de formato corto
- Flujo de producción de animación
- Edición y colorización en postproducción

## Fundamentos de fotografía

### Triángulo de exposición

```
┌─────────────────────────────────────────────────────────────────┐
│  Triángulo de exposición — Exposure Triangle                    │
│                                                                 │
│              Diafragma / Aperture                               │
│                 /\                                              │
│                /  \                                             │
│               /    \                                            │
│              /      \                                           │
│             /        \                                          │
│            /          \                                         │
│           /            \                                        │
│          /______________\                                       │
│    Obturador Shutter    ISO Sensibilidad                        │
│                                                                 │
│  Diafragma (f/1.4 – f/22)                                       │
│  ├─ Abierto (número bajo): poca profundidad, fondo desenfocado  │
│  └─ Cerrado (número alto): mucha profundidad, todo nítido       │
│                                                                 │
│  Obturador (1/4000s – 30s)                                      │
│  ├─ Alta velocidad: congela el movimiento                       │
│  └─ Baja velocidad: motion blur, estelas de luz                 │
│                                                                 │
│  ISO (100 – 12800+)                                             │
│  ├─ ISO bajo: imagen limpia y detallada                         │
│  └─ ISO alto: sirve en poca luz, pero introduce ruido           │
└─────────────────────────────────────────────────────────────────┘
```

### Reglas de composición

```markdown
## Composición básica

### Regla de tercios
- Divide el encuadre en una retícula de 3×3
- Coloca el sujeto en los puntos de intersección
- Sitúa el horizonte en la línea superior o inferior

### Líneas guía
- Usa líneas para conducir la mirada
- Caminos, ríos, barandales
- Que apunten al sujeto

### Encuadre dentro del encuadre
- Enmarca al sujeto con elementos del primer plano
- Marcos de puerta, ventanas, ramas
- Aporta capas y profundidad

### Simetría y equilibrio
- Simetría perfecta = estabilidad, solemnidad
- Asimetría = dinamismo, tensión
- Equilibra el peso visual

### Espacio negativo
- El vacío refuerza el punto focal
- Da "espacio para respirar" al sujeto
- Estética minimalista
```

### Uso de la luz

| Tipo de luz | Característica | Ideal para |
|-------------|----------------|------------|
| **Luz frontal** | Plana, con pocas sombras | Registro, foto de documento |
| **Luz lateral** | Volumétrica, con sombras | Retrato, arquitectura |
| **Contraluz** | Silueta, halo | Atmósfera, pieza artística |
| **Luz cenital** | Sombras duras | Evitar al mediodía |
| **Hora dorada** | Cálida y suave | Paisaje, retrato |
| **Hora azul** | Fría, enigmática | Ciudad, nocturnas |

### Movimientos de cámara

| Movimiento | Efecto | Cuándo usarlo |
|------------|--------|---------------|
| **Push in** | Énfasis, acercamiento | Revelar el punto clave |
| **Pull out** | Revela el conjunto | Cierre, transición |
| **Pan** | Desplazamiento horizontal | Seguimiento, presentar el entorno |
| **Tilt** | Desplazamiento vertical | Mostrar altura |
| **Track** | Acompaña al sujeto | Caminata, persecución |
| **Órbita** | Giro de 360° | Momento dramático |
| **Cámara en mano** | Inmediatez, presencia | Documental, tensión |

### Uso de los tipos de plano

```markdown
## Tipos de plano — Shot Types

### Plano general (Wide Shot)
- Establece la escena
- Muestra el entorno
- El personaje se ve pequeño

### Plano entero (Full Shot)
- Cuerpo completo
- Acción legible
- Luce el vestuario

### Plano medio (Medium Shot)
- De la cintura hacia arriba
- Escenas de diálogo
- Gestualidad de manos

### Primer plano (Close-up)
- De los hombros hacia arriba
- Expresión emocional
- Línea de diálogo importante

### Primerísimo primer plano (Extreme Close-up)
- Detalle de ojos o manos
- Emoción intensa
- Detalle de objeto
```

## Fundamentos de animación

### Los 12 principios

```markdown
## Los 12 principios de animación de Disney

1. **Squash & Stretch** (compresión y estiramiento)
   - Conservar el volumen
   - Comunicar peso y elasticidad

2. **Anticipación** (Anticipation)
   - Agacharse antes de saltar
   - Retraer el brazo antes del golpe

3. **Puesta en escena** (Staging)
   - Comunicar la intención con claridad
   - Guiar la mirada del espectador

4. **Directo vs. pose a pose** (Straight Ahead & Pose to Pose)
   - Directo: fluido, orgánico
   - Pose a pose: preciso, controlable

5. **Acción continuada y superpuesta** (Follow Through & Overlapping)
   - El retardo del cabello y la ropa
   - Aporta naturalidad

6. **Entradas y salidas lentas** (Slow In & Slow Out)
   - El movimiento arranca y termina lento
   - Y acelera en medio

7. **Arcos** (Arcs)
   - El movimiento natural es curvo
   - Evita la sensación mecánica

8. **Acción secundaria** (Secondary Action)
   - Micromovimientos además de la acción principal
   - Enriquecen al personaje

9. **Timing** (Timing)
   - El número de cuadros define la velocidad
   - Afecta la sensación de peso

10. **Exageración** (Exaggeration)
    - Más intenso que la realidad
    - Resalta el rasgo distintivo

11. **Dibujo sólido** (Solid Drawing)
    - Entender la estructura tridimensional
    - Peso y equilibrio

12. **Atractivo** (Appeal)
    - Carisma del personaje
    - Que dé ganas de verlo
```

## Postproducción y edición

### Ritmo de edición

```markdown
## Principios de edición

### Corte en movimiento
- Cambia de plano durante la acción
- Mantiene la fluidez

### Corte en reposo
- Cambia durante una pausa
- Habitual en escenas de diálogo

### Regla de los 180 grados
- Conserva la posición relativa de los personajes
- Evita cruzar el eje

### J-Cut / L-Cut
- J-Cut: el audio entra antes que la imagen
- L-Cut: la imagen se mantiene después del audio
- Aumentan la fluidez
```

### Fundamentos de colorización

| Parámetro | Función | Ejemplo |
|-----------|---------|---------|
| Exposición | Brillo general | Levantar una toma subexpuesta |
| Contraste | Distancia entre luces y sombras | Ganar volumen |
| Temperatura | Frío / cálido | Cálido para calidez emocional |
| Tinte | Verde / magenta | Corrección de tonos de piel |
| Saturación | Intensidad de color | Desaturar para look cinematográfico |
| Curvas | Ajuste fino | Curva en S para más contraste |
